T3 Code architecture tutorial

How the app works from UI click to agent output

T3 Code is a local coding-agent workspace. The web UI sends typed RPC commands to a local server, the server records domain events, provider adapters run Codex, Claude, Cursor, or OpenCode, and the UI updates through live subscriptions.

Application layers
Web

React/Vite client. Renders projects, threads, chat, git status, terminals, and settings.

Desktop

Electron shell. Provides native dialogs, menus, storage, updates, and backend process management.

Server

Local backend. Owns auth, RPC, orchestration, providers, git, terminals, persistence, and startup.

Contracts

Shared schemas and RPC definitions used by the web client and server to stay type-aligned.

The short version

The server is the source of truth. The UI is mostly a typed client over HTTP and WebSocket RPC.

1. Startup

src/bin.ts builds the CLI. The CLI resolves config, then launches src/server.ts, which composes all Effect layers.

3. Work

User actions become orchestration commands. Commands create events. Reactors turn events into provider calls, checkpoints, and live UI updates.

Key subsystems

Each subsystem is isolated behind an Effect service and then wired into the server layer.

Auth

Browser sessions, bearer sessions, pairing links, client revocation, and short-lived WebSocket tokens live under src/auth.

Providers

Provider drivers materialize instances. Each instance owns a snapshot, adapter, and text-generation implementation.

Orchestration

Commands become events. Events update projections and trigger reactors. This is the heart of thread and project state.

Git and VCS

Git status, refs, worktrees, pull, source-control detection, PR lookup, and publishing are split across src/git, src/vcs, and src/sourceControl.

Terminals

Terminal sessions use PTY adapters, persist history, stream output, and support open/write/resize/restart/close RPC calls.

Checkpointing

Checkpoints capture git state before and after turns, then compute per-turn file diffs for the UI.

The core idea

T3 Code is not just a chat UI. It is a local event-sourced control plane for coding agents. The UI sends commands, the server records events, reactors perform side effects, and projections keep the interface fast and consistent.
